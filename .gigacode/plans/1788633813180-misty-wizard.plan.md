# Plan: Remove VST from Master, Add Master EQ Window

## Overview
Remove VST plugin support from the master output chain and replace it with a parametric equalizer identical to the track EQ, but in a separate floating window.

## Current Architecture

### Audio Processing Chain (pcm_air_player.py)
```
Raw PCM → Track EQ → HighCutSweep → Track Gain → _emit_wet_pcm()
    → Master VST FX → Clip → Int16 → QAudioSink
```

### Key Components
- **Track EQ**: `EqProcessor` per player, controlled via `ParametricEqView` in `FilePropertiesPanel`
- **Master FX**: `MasterFxHost` (VST3/AU via pedalboard), controlled via `MasterFxPanel` in `FilePropertiesPanel`
- **EQ State**: `EqState` stored in `AudioPlayer._track_eq_state` dict (path-keyed)
- **EQ DSP**: `app/eq_dsp.py` — `EqProcessor` class with live coefficient swap

### 3. Wire Master EQ to Audio Pipeline
**File**: `app/pcm_air_player.py`

Modify `_emit_wet_pcm()` to apply master EQ after track EQ but before VST FX:
```python
def _emit_wet_pcm(self, wet: np.ndarray) -> None:
    frames = int(wet.size) // _TARGET_CHANNELS
    self._capture_spectrum(wet)
    
    # NEW: Apply master EQ
    if self._master_eq is not None:
        wet = self._master_eq.process_interleaved(wet)
    
    # OLD: Master VST FX (will be removed)
    host = self._master_fx
    if host is not None and host.is_active():
        try:
            wet = host.process_interleaved(
                self._master_fx_copy, wet, float(self._sample_rate)
            )
        except Exception:
            pass
    
    clipped = np.clip(wet, -1.0, 1.0)
    pcm = (clipped * 32767.0).astype(np.int16)
    self._byte_pending.extend(pcm.tobytes())
    self._frames_played += frames
```

Add to `__init__`:
```python
self._master_eq = None  # EqProcessor
```

Add setter:
```python

    self._master_eq = eq_processor
```

Call `set_master_eq` for all players from `AudioPlayer.__init__`.

def toggle_master_eq_window(self):
    if self._master_eq_window is None:
        self._master_eq_window = MasterEqWindow(self)
        self._master_eq_window.eqChanged.connect(self._on_master_eq_changed)

### 7. Master EQ State Management
**File**: `app/player.py`

Implement `_on_master_eq_changed()`:
```python
def _on_master_eq_changed(self):
    if not hasattr(self, 'master_eq_window'):
        return
    state = self.master_eq_window.state()
    self._master_eq_state = state.to_dict()
    # Push to all players
    for player in self._players:
        player.set_eq_state(state)  # reuse existing EqProcessor.set_state
    self._save_master_eq()
```

Add debounced save:
```python
def _save_master_eq(self):
    if not hasattr(self, '_master_eq_save_timer'):
        self._master_eq_save_timer = QTimer(self)
        self._master_eq_save_timer.setSingleShot(True)
        self._master_eq_save_timer.timeout.connect(self.save_config)
    self._master_eq_save_timer.start(400)
```
